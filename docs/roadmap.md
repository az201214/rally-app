# Rally Roadmap

## Foundation

- Application shell with Riverpod and GoRouter
- Centralized Material 3 design system
- Shared UI component library
- Asset and documentation structure

## Authentication experience

- Final authentication screen designs
- Form state and validation
- Authentication domain contracts
- Backend integration after architecture review

## Matchmaking

- Player preference and availability models
- Match discovery experience
- Compatibility and match-status presentation
- Real data integration

## Community and clubs

- Club discovery and membership
- Player profiles and community features
- Notifications and activity surfaces

Each milestone should deliver a tested vertical slice. Backend integrations must
not be represented by production fake implementations.
